# Fazer um projeto que mostre uma frase da letra da música por dia

## Motivação
Este programa é bem simples, ele serve únicamente para ser um desafio divertido que saiu da minha cabeça enquanto eu provavelmete cantava enquanto lavava a louça (rsrs). É apenas um programa para testar minhas habilidades em C#.

## Funcionalidade do programa
Este sistema criará um arquivo txt, este arquivo será atualizado diariamente com a próxima frase da música. Porém, este arquivo não será atualizado automaticamente, para mantê-lo atualizado o usuário deve abrir o arquivo todos os dias ou de vez em quando para ver a continuação da letra. 
Exemplo de como funciona para uma melhor explicação:
Imagine que hoje é dia 18/09/2025, o programa usará a data do dia que estou criando este programa, no caso no dia 16/09/2025.
Dia 16, se o programa for aberto nesse dia, a primeira frase da letra inteira da música aparecerá. No dia 18 já existirão 3 frases da letra da música no arquivo, mesmo se o programa for executado pelo usuário no dia 18 pulando o dia 17.

## Requisitos funcionais
 - Este programa está usando a data do dia 16/09/2025.
 - Criar um arquivo caso o arquivo não exista.
 - Atualizar o arquivo caso o arquivo já exista.
 - Atualizar o arquivo apenas se o programa não tiver sido executado antes.

## Requisitos não funcionais
 - Adicionar mais uma música no programa.
 - Adicionar um mini menu para decidir qual música o usuário quer ver.
